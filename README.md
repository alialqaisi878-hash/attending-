# برنامج الحضور والانصراف

تطبيق ويب بسيط لتسجيل حضور وانصراف الموظفين اونلاين، بالعربي ومن الموبايل أو الكمبيوتر.

## المزايا
- **صفحة الموظف** (`/`): يكتب كود الموظف والرمز السري ويضغط "تسجيل حضور" أو "تسجيل انصراف". يتسجل الوقت حسب توقيت بغداد، ويتحفظ موقعه (GPS) إذا سمح.
- **لوحة المدير** (`/admin.html`):
  - اليوم: من حاضر، من متأخر، من غائب، مع رابط الموقع على الخريطة.
  - التقارير: لأي فترة ولأي موظف، مع دقائق التأخير وساعات العمل، وتنزيل Excel (CSV).
  - الموظفين: إضافة، تغيير الرمز السري، إيقاف/تفعيل.
  - الإعدادات: بداية ونهاية الدوام وفترة السماح.

## التشغيل
يحتاج Node.js 22.13 أو أحدث.

```bash
npm install
ADMIN_PASSWORD=كلمة-سر-قوية npm start
```
ثم افتح http://localhost:3000

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ADMIN_PASSWORD` | `admin123` | كلمة مرور المدير (غيّرها!) |
| `PORT` | `3000` | المنفذ |
| `DB_PATH` | `attendance.db` | ملف قاعدة البيانات (SQLite) |
| `APP_TZ` | `Asia/Baghdad` | المنطقة الزمنية |
