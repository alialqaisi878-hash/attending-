# بصمة: الحضور والانصراف والرواتب للشركات

نسخة تجارية تنباع لأكثر من شركة. سيرفر واحد، وكل شركة إلها رابط خاص وبيانات منفصلة تماماً (ملف قاعدة بيانات لكل شركة)، وصاحب البرنامج يدير الشركات والاشتراكات من لوحة وحدة.

| الرابط | لمنو |
|---|---|
| `https://الدومين/` | صفحة تعريف بالبرنامج + دخول برمز الشركة |
| `https://الدومين/super` | لوحة صاحب البرنامج |
| `https://الدومين/رمز-الشركة/` | الموظفين (يضيفوه للشاشة الرئيسية ويصير مثل التطبيق) |
| `https://الدومين/رمز-الشركة/admin.html` | مدير الشركة والمحاسب |

## لوحة صاحب البرنامج
- إضافة شركة: الاسم، الرمز بالرابط، تاريخ انتهاء الاشتراك (الافتراضي تجربة 14 يوم)، أقصى عدد موظفين، السعر الشهري، رقم التواصل.
  بعد الإضافة تطلع رسالة جاهزة (الرابط + باسورد المدير) تنسخها أو تدزها واتساب.
- تجديد بضغطة (+ شهر / + سنة)، إيقاف وتفعيل، باسورد مدير جديد، «دخول كمدير» للدعم الفني، حذف (الملف ينحفظ بمجلد `deleted`).
- إحصائيات: عدد الشركات، الفعّالة، اللي تنتهي خلال أسبوع، عدد الموظفين، الدخل الشهري.
- سجل بكل العمليات.

لما ينتهي الاشتراك أو تنوقف الشركة: الصفحات تفتح وتعرض رسالة فيها رقم التواصل، والبصمة والدخول يوقفون. البيانات تبقى محفوظة وترجع بالتجديد. مدير الشركة يشوف تنبيه قبل الانتهاء بأسبوع.

## مزايا كل شركة
كل مزايا برنامج الحضور: بصمة بموقع العمل بس، قفل الجهاز، الدوامات، الإجازات ورصيدها، الغياب، الرواتب (اليومية، سماحية التأخير الشهرية، سعر ساعة التأخير والإضافي، المكافآت والسلف)، فورمة الراتب، Excel، تنبيهات التلفون، البصمة بدون نت، حساب المحاسب، سجل التغييرات، ربط Webhook.

وكل شي خاص بالشركة صار إعداد تغيّره الشركة بنفسها: الاسم، الشعار (يطلع بأيقونة التلفون وفورمة الراتب)، اللون، العملة، المنطقة الزمنية، أرقام الرواتب، وملاحظة بصفحة الدخول.

## الحماية
- كل شركة بملف SQLite منفصل، والتوكن مال شركة ما يشتغل بشركة ثانية.
- إيقاف الدخول مؤقتاً بعد 10 محاولات باسورد غلط.
- رابط Webhook ما يكدر يوصل للسيرفر نفسه أو شبكته الداخلية.
- نسخة احتياطية يومية لكل الشركات (آخر 14 يوم) بمجلد `data/backups`.

## التشغيل محلياً
يحتاج Node.js 22.13 أو أحدث.
```bash
npm install
SUPER_PASSWORD=باسورد-قوي npm start
```

| المتغير | الوصف |
|---|---|
| `SUPER_PASSWORD` | باسورد لوحة صاحب البرنامج أول مرة (بعدين يتغير من اللوحة). مطلوب. |
| `DATA_DIR` | مجلد البيانات (الافتراضي `data`) |
| `PORT` | المنفذ (3000) |
| `PRODUCT_NAME` / `SUPPORT_PHONE` | القيم الأولى لاسم البرنامج ورقم التواصل (تتغير من اللوحة) |
| `VAPID_SUBJECT` | رابط الموقع لخدمة الإشعارات |

## التنصيب على السيرفر (Docker + Traefik)
```bash
bash deploy/install.sh hudoor.example.com
```
يسوي حاوية `hudoor-saas` بمجلد `/root/hudoor-saas` وما يلمس أي برنامج ثاني. يطبع باسورد لوحة صاحب البرنامج أول مرة. نفس الأمر بدون دومين يحدّث البرنامج.
