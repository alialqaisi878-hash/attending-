# برنامج الحضور والانصراف

تطبيق ويب بسيط لتسجيل حضور وانصراف الموظفين اونلاين، بالعربي ومن الموبايل أو الكمبيوتر.

## المزايا
- **حساب لكل موظف**: يدخل باسم مستخدم وكلمة مرور، ويشوف واجهته الرئيسية: أزرار البصمة، حالته اليوم، ملخص الشهر، راتبه التقديري، وسجل أيامه. ويكدر يغيّر كلمة المرور ويطبع فورمة راتبه.
- **تحديد مكان البصمة**: المدير يحدد موقع العمل والمسافة المسموحة، والبصمة من خارج المكان تنرفض.
- **الراتب لكل موظف**: الراتب الشهري، وقت بداية ونهاية الدوام، الساعة الي يبدي بيها الأوفر تايم، ومضاعف أجر الأوفر تايم.
- **الإجازات**: المدير يحدد أيام الإجازة ونوعها: مدفوعة (بدون خصم) أو بقطع راتب. أي يوم دوام بدون بصمة وبدون إجازة يُحسب غياب وينخصم.
- **فورمة الراتب**: كشف شهري لكل موظف جاهز للطباعة (A4) فيه تفاصيل الراتب والسجل اليومي وأماكن التوقيع.
- **تنبيهات على الموبايل**: تذكير قبل بداية الدوام، وتذكير ثاني إذا ما بصم، وتذكير بالانصراف بعد نهاية الدوام.
- **لوحة المدير**: اليوم، الموظفين، الإجازات، الرواتب، التقارير (مع تنزيل Excel)، الإعدادات.

### طريقة حساب الراتب
- الراتب اليومي = الراتب الشهري ÷ عدد أيام الشهر (30 افتراضياً، يتغير من الإعدادات).
- أجر الساعة = الراتب اليومي ÷ ساعات الدوام.
- الخصم = (أيام الغياب + أيام الإجازة بقطع راتب) × الراتب اليومي.
- الأوفر تايم = الدقائق بعد ساعة بداية الأوفر تايم (وكل دوام أيام العطلة) × أجر الساعة × المضاعف.
- الصافي = الأساسي − الخصم + أجر الأوفر تايم.

### ملاحظات مهمة
- تحديد الموقع والتنبيهات يحتاجن البرنامج يكون منشور على **HTTPS**.
- بالآيفون: التنبيهات تشتغل بس إذا الموظف ضاف البرنامج للشاشة الرئيسية (Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية).

## التشغيل
يحتاج Node.js 22.13 أو أحدث.

```bash
npm install
ADMIN_PASSWORD=كلمة-سر-قوية npm start
```
ثم افتح http://localhost:3000

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ADMIN_PASSWORD` | `admin123` | كلمة مرور المدير (غيّرها!) |
| `PORT` | `3000` | المنفذ |
| `DB_PATH` | `attendance.db` | ملف قاعدة البيانات (SQLite) |
| `APP_TZ` | `Asia/Baghdad` | المنطقة الزمنية |
| `VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY` | تتولد تلقائياً | مفاتيح الإشعارات |
| `VAPID_SUBJECT` | `mailto:admin@example.com` | بريد التواصل لخدمة الإشعارات |
